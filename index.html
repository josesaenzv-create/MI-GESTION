🔌 Conector Universal de Sesión Única (SSO)

En v2.0 el contenedor inyecta automáticamente el tema global (Modo Noche, letra y tamaño) y pre-carga tu sesión. Solo añade este bloque en las apps nuevas que quieran leer window.CREDIBAN_SSO: 

// Escucha la sesión iniciada enviada por Mi Gestión Crediban
window.addEventListener("message", (event) => {
  if (!event.data || !event.data.type) return;

  if (event.data.type === "CREDIBAN_SSO_SESSION") {
    const sesion = event.data.session;
    const prefs  = event.data.preferencias;
    window.CREDIBAN_SSO = sesion;
    if (typeof iniciarConSesionContenedor === "function") {
      iniciarConSesionContenedor(sesion, prefs);
    }
  }
});
if (window.parent !== window) {
  window.parent.postMessage({ type: "CREDIBAN_REQUEST_SESSION" }, "*");
}
