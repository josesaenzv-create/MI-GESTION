🔌 Conector Universal de Sesión Única (SSO)

Cuando quieras que una de tus apps internas entre directo sin volver a pedir usuario y contraseña al abrirse dentro de Mi Gestión Crediban, pega este bloque al inicio de su <script>: 

// Escucha la sesión iniciada enviada por Mi Gestión Crediban
window.addEventListener("message", (event) => {
  if (!event.data || !event.data.type) return;

  if (event.data.type === "CREDIBAN_SSO_SESSION") {
    const sesion = event.data.session; // { usuario, nombreCompleto, cargo, cargoNormalizado, sede, sedesPermitidas, correo }
    const prefs  = event.data.preferencias; // { tema: 'light'|'dark', fuente, tamanoTexto, colorAcento }
    window.CREDIBAN_SSO = sesion;
    // Llama aquí a la función de tu app que oculta su login y abre el panel con `sesion`
    if (typeof iniciarConSesionContenedor === "function") {
      iniciarConSesionContenedor(sesion, prefs);
    }
  }
});
// Solicitar sesión apenas cargue la pestaña
if (window.parent !== window) {
  window.parent.postMessage({ type: "CREDIBAN_REQUEST_SESSION" }, "*");
}
